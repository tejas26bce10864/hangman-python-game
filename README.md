# Python Hangman Game
A command-line interface (CLI) implementation of the classic Hangman game written in python, this game support two modes: guessing single word and guessing sentences
## Project Structure
-'hangman.py' - Main application logic and terminal UI.

-'nouns.txt' - Text dataset containing single words for Word Mode.
- 'sentences.txt' - Text dataset containing full sentences for Sentence Mode.

## Requirements & Prerequisites
- Python 3.14.7 installed on your system.
- Standard Python libraries (uses built-in 'random' module; no external package installation needed).
